# Recimed — Landing Page

Landing page de fisioterapia especializada para a Recimed (Recife-PE).

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React Icons
- shadcn/ui components
